# PANDO-MAKER

PANDO-MAKER — локальный веб-редактор аватаров На'ви на **React + Vite + Three.js + React Three Fiber + face-api.js + TailwindCSS + Zustand**.

## Возможности

- Загрузка селфи и автоматический анализ лица (глаза/нос/ширина/угол).
- Генерация базового аватара На'ви на основе распознавания.
- Ручная настройка: **цвет кожи**, **цвет глаз**, **прическа**, **клан**.
- Режимы клана:
  - **Оматикайя (лес)** — более темная кожа, зеленое свечение, листовые элементы.
  - **Меткайина (вода)** — бирюзовая кожа, волновые паттерны, ракушки.
- 3D-сцена в реальном времени с вращением мышью.
- Случайный аватар.
- Сохранение/загрузка пресета в localStorage.
- Экспорт PNG 2048x2048 с прозрачным фоном.

## Запуск на Windows

1. Установите **Node.js 18+**.
2. Откройте **PowerShell** или **CMD**.
3. Перейдите в папку проекта:

```bash
cd pando-maker
```

4. Установите зависимости:

```bash
npm install
```

5. Запустите приложение:

```bash
npm run dev
```

6. Откройте адрес из терминала (обычно `http://localhost:5173`).

## Production-сборка

```bash
npm run build
npm run preview
```

## Важно для face-api.js

Чтобы работало распознавание лица, поместите модели в каталог:

`public/models`

Минимальный набор файлов:

- `tiny_face_detector_model-weights_manifest.json`
- `tiny_face_detector_model-shard1`
- `face_landmark_68_tiny_model-weights_manifest.json`
- `face_landmark_68_tiny_model-shard1`

Без этих файлов приложение будет работать, но анализ лица будет недоступен.
